# Section browser and highlighted Markdown source## Status: accepted (2025-12-12)## Feature 1: section browser (left sidebar)A collapsible left sidebar in the host app, like the navigation pane inMicrosoft Word. It lists the document's sections (headings) with theirenter outline; clicking one scrolls the document to that section.Contract:- Engine: `outlineOf(doc)` in `src/engine/outline.ts` returns  `OutlineEntry { blockIndex, level, text }[]` — pure, headless,  tested in `tests/engine/outline.test.ts`.- Component (`<folio-doc>`):  - `getOutline(): OutlineEntry[]`  - `revealBlock(blockIndex)` scrolls smoothly to the block and  moves focus to it.  - `firstVisibleBlockIndex()` reports which block is at the top of  the viewport (used to highlight the active section).- Host: an icon-only `☰` toggle (tooltip "Sections", no text label - consistent with the other toolbar controls) at the left edge of the header (above the sidebar it controls) toggles the sidebar  (`hidden` attribute). The active section highlights while the  document scrolls; clicking a section in Markdown view parses the  source first and reveals the rendered section.Acceptance: an agent playing a new user, without instructions, opens/closes the sidebar, sees all headings, and clicks one to zoom to it(eval: `evals/section-browser-first-contact.md`).## Feature 2: Markdown source with syntax highlightingThe Markdown view is a text editor experience like VS Code: propercode coloring, monospace, line-number gutter, while remaining aplain text editing surface (a native textarea — no code mirror, nonew dependency per ADR-0007).Contract:- `highlightMarkdown(src)` in `src/render/highlight.ts` returns  per-line typed tokens (`MdLine { tokens: MdToken[] }`,  `MdToken { kind, text }`). Pure string computation, no HTML  strings, no injection surface; tested in  `tests/render/highlight.test.ts` including a round-trip property:  concatenated token text always equals the source.- Host: a transparent `textarea` overlays a highlighted `<pre>`; both  share identical font metrics so the caret sits exactly on the  colored text. Token kinds map to CSS classes `tk-<kind>` in  `index.html`. The textarea auto-grows to its content so the  overlay never desynchronizes.## Notes- The outline and highlighter are UI-free and golden/property tested;only the thin host glue lives outside the engine/render modules.
