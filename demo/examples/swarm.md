# A murmuration, simulated

## From Python: frames as a dataset

A compute block generates the frames and publishes them as a table;
the figure plays any such dataset (`source: @frames`). Edit the code
or the table and the figure follows - still no run button. The
sequence plays in a loop while the document is open. The sim is a
wandering vortex: every bird orbits a slowly drifting centre with its
own radius and angular speed, a radial wobble makes the cloud breathe,
and a little noise keeps it organic - so it swirls and morphs like a
real swallow murmuration instead of settling into a static blob:

```python out=frames
import math, random
random.seed(7)
W, H = 640, 360
N, F = 24, 18
birds = [{"r0": 10 + random.random() ** 1.8 * 100,
          "w": (0.10 + random.uniform(-0.03, 0.03)) * (1 if i % 4 else -1),
          "th": random.uniform(0, math.pi * 2),
          "ph": random.uniform(0, math.pi * 2),
          "sq": random.uniform(0.55, 0.95)} for i in range(N)]
frames = []
for f in range(F):
    ax = W / 2 + math.sin(f * 0.03) * W * 0.22
    ay = H / 2 + math.cos(f * 0.042) * H * 0.18
    rot = f * 0.028
    for i, b in enumerate(birds):
        r = b["r0"] * (1 + 0.38 * math.sin(f * 0.23 + b["ph"]))
        th = b["th"] + b["w"] * f + rot
        x = ax + r * math.cos(th) + random.uniform(-2.5, 2.5)
        y = ay + r * math.sin(th) * b["sq"] + random.uniform(-2.5, 2.5)
        frames.append({"frame": f, "agent": f"bird-{i}", "x": round(x, 1), "y": round(y, 1)})
```
