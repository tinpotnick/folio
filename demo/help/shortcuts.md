## Getting help

Help opens in a panel beside your document, so you can read a topic
and try it at the same time: the **?** toolbar button, **F1** (even
while typing), or the **?** key when you are not typing - each opens
and closes it. **All topics** goes back to the list;
the search box above it finds a topic by what it says. Ctrl+K finds
help topics too, and opens the panel at the one you pick.
